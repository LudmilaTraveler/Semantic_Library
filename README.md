
ТЕХНИЧЕСКИЙ ПАСПОРТ ПРОЕКТА: СЕМАНТИЧЕСКАЯ БИБЛИОТЕКА

1. НАЗНАЧЕНИЕ СИСТЕМЫ
Программный комплекс предназначен для автоматизированного семантического поиска, индексации и анализа научно-технических публикаций. Система обеспечивает поиск документов не по ключевым словам, а по смысловому контексту запроса с использованием векторных представлений текста.
2. АРХИТЕКТУРА И ТЕХНОЛОГИЧЕСКИЙ СТЕК
Архитектура построена по модульному принципу и включает в себя следующие компоненты:
• Модуль векторизации: Представлен моделями семейства Sentence-BERT (SBERT) для генерации плотных эмбеддингов фиксированной размерности.
• Модуль хранения и поиска: Векторная база данных Qdrant, обеспечивающая индексацию векторов и расчет метрик косинусного сходства.
• Интерфейсный слой: Асинхронный веб-сервер на базе FastAPI для обработки поисковых и административных запросов.
• Среда развертывания: Изолированные контейнеры Docker для обеспечения воспроизводимости инфраструктуры базы данных.
3. АЛГОРИТМ ФУНКЦИОНИРОВАНИЯ
Процесс работы системы разделен на два независимых контура:
• Контур индексации: Входной текстовый массив разбивается на смысловые фрагменты. Модель SBERT формирует для каждого фрагмента вектор признаков. Векторы вместе с метаданными документа (автор, название, дата) передаются в локальную коллекцию Qdrant, где строится поисковый индекс.
• Контур поиска: Поисковый запрос пользователя преобразуется в вектор аналогичной размерности. База данных Qdrant выполняет поиск K-ближайших соседей (алгоритм k-NN) в векторном пространстве и возвращает список наиболее релевантных документов с указанием коэффициента совпадения.
4. РАЗВЕРТЫВАНИЕ И ЗАПУСК СИСТЕМЫ
Шаг 1. Клонирование репозитория и подготовка окружения:
git clone git@github-ludmila:LudmilaTraveler/Semantic_Library.git
cd Semantic_Library
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
Шаг 2. Запуск контейнера векторной базы данных Qdrant:
docker run -p 6333:6333 -v ${PWD}/qdrant_storage:/qdrant/storage qdrant/qdrant
Шаг 3. Запуск веб-сервиса FastAPI:
uvicorn main:app --reload
5. КОНФИДЕНЦИАЛЬНОСТЬ И БЕЗОПАСНОСТЬ ДАННЫХ
Локальное хранилище qdrant_storage и локальный кэш весов нейросетевых моделей Hugging Face жестко изолированы на уровне конфигурации gitignore. Исходный код репозитория не содержит бинарных индексов базы данных, конфигурационных файлов среды окружения и весов моделей.
6. СТРУКТУРА ИСХОДНОГО КОДА
main.py - точка входа, конфигурация веб-сервера и описание эндпоинтов API.
config.py - инициализация параметров подключения к СУБД и выбор модели эмбеддингов.
services/ - пакет модулей для взаимодействия с Qdrant и трансформации текста в векторы.
requirements.txt - спецификация зависимостей проекта с фиксацией версий.
.gitignore - инструкции для исключения системного и платформозависимого мусора из контроля версий.
